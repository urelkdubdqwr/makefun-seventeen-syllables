One haiku about debugging: three lines in the 5-7-5 syllable shape, at most 200 characters. main.py writes it to /output/entry.txt.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py && cat out/entry.txt
```
